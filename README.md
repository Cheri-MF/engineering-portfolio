# Cheri Favel | SAMA Engineering Portfolio

This standalone portfolio draws on the ADIPEC and WETEX designs for general engineering applications.

1. Extract the ZIP and open `index.html` to preview the site.
2. Create a separate repository, for example `engineering-portfolio`.
3. Upload the extracted files and folders to the root of the new repository's `main` branch. Include `.nojekyll`.
4. In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/ (root)**. Save and use the URL shown in Pages.

GitHub Pages uses the account name in the default address, `https://<account>.github.io/engineering-portfolio/`. To use a public address without a personal or organization name, configure a neutral custom domain in **Settings → Pages**.

[GitHub Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
